Solmara is an original open-world crime game set in the fictional sun-soaked city of Solmara: explore on foot or by car, steal cars, outrun the Solmara PD, and run jobs for the fixer Mara across a four-mission story — with traffic, pedestrians, a wanted system, combat, a HUD with a minimap, and a synthesized soundtrack. Built with three.js, playable offline in a desktop browser.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
